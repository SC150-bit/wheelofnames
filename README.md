# Rigged Wheel of Names

A manipulative lucky wheel that lets you control who wins

## Features

- **Truly Random Mode**: Works as a fair random picker by default
- **Secret Rig Mode**: Press `Ctrl+U` to open a hidden popup where you can choose who should win
- **Simple Interface**: Easy to use wheel interface for picking names

## Usage

1. Add names to the wheel
2. Spin the wheel for a random selection
3. **Secret Feature**: Press `Ctrl+U` to open the rig popup and select who you want to win on the next spin
